# WorkChat-skill

帮助职场新人自然、简洁地起草工作消息，让沟通清楚并推动事情往前走。

## 能做什么

- 起草向领导或同事提问的消息
- 回复同事或领导，清楚表达进度、影响和下一步
- 理顺已有草稿，保留事实、重点和明确请求

## 安装到 Codex

1. 点击仓库中的 **Code → Download ZIP**，下载并解压。
2. 将 `skills/workplace-chat` 文件夹复制到当前项目的 `.agents/skills/`。
3. 如需在所有项目中使用，可复制到 `~/.agents/skills/`。
4. 新开一个 Codex 会话后即可使用。

## 使用示例

在 Codex 中直接描述你的情况，例如：

> 提问。运营｜初级｜直属领导。我想确认这项需求的优先级，帮我写一条自然、简短的消息。
